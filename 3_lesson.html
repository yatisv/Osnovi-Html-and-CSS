📚 1. Теоретический материал

Что такое списки в HTML?

Списки позволяют организовать информацию в виде перечня элементов. В HTML существует три основных типа списков:

1. Маркированный список (<ul>)

Используется для перечисления элементов, где порядок не важен. Каждый элемент маркируется маркером (точкой, кружком или квадратом).

Типы маркеров для списка:

Атрибут type позволяет изменить вид маркера (хотя в современном HTML для этого чаще используют CSS):

type="disc" (по умолчанию)
  • Яблоки
  • Бананы

<ul type="disc">
    <li>Яблоки</li>
    <li>Бананы</li>
</ul>
type="circle"
  • Яблоки
  • Бананы

<ul type="circle">

    <li>Яблоки</li>

    <li>Бананы</li>

</ul>
type="square"
  • Яблоки
  • Бананы

<ul type="square">

    <li>Яблоки</li>

    <li>Бананы</li>

</ul>

2. Нумерованный список (<ol>)

Используется, когда важен порядок элементов. Элементы нумеруются автоматически.

Пример нумерованного списка:
  1. Первый шаг
  2. Второй шаг
  3. Третий шаг

<ol>

    <li>Первый шаг</li>

    <li>Второй шаг</li>

    <li>Третий шаг</li>

</ol>
Типы нумерации (атрибут type):
type="1" (цифры)
  1. Первый
  2. Второй
type="A" (заглавные буквы)
  1. Первый
  2. Второй
type="a" (строчные буквы)
  1. Первый
  2. Второй
type="I" (римские заглавные)
  1. Первый
  2. Второй

3. Список определений (<dl>)

Используется для создания словаря или списка терминов с определениями.

Пример списка определений:
HTML
Язык гипертекстовой разметки
CSS
Таблицы каскадных стилей

<dl>
    <dt>HTML</dt>
    <dd>Язык гипертекстовой разметки</dd>
    <dt>CSS</dt>
    <dd>Таблицы каскадных стилей</dd>
</dl>

Вложенные списки

Списки можно вкладывать друг в друга, создавая многоуровневую структуру:

Пример вложенного списка:
  • Фрукты
    • Яблоки
    • Груши
    • Апельсины
  • Овощи
    • Морковь
    • Картофель
    • Капуста
  • Ягоды
    • Клубника
    • Малина

<ul>

    <li>Фрукты 
        <ul>

            <li>Яблоки</li>
            <li>Груши</li>
            <li>Апельсины</li>
        </ul>
    </li>
    <li>Овощи
        <ul>
            <li>Морковь</li>
            <li>Картофель</li>
            <li>Капуста</li>
        </ul>
    </li>
    <li>Ягоды
        <ul>
            <li>Клубника</li>
            <li>Малина</li>
        </ul>
    </li>
</ul>

💡 Аналогия: Оглавление книги

Вложенные списки похожи на оглавление: есть главные главы (первый уровень), а внутри них — параграфы (второй уровень), а внутри параграфов — подпункты (третий уровень).

2. Таблицы в HTML

Таблицы используются для представления данных в виде строк и столбцов.

Основные теги таблиц:

  • <table> — контейнер для всей таблицы
  • <tr> (table row) — строка таблицы
  • <td> (table data) — обычная ячейка с данными
  • <th> (table header) — заголовочная ячейка (жирный текст по центру)
Пример простой таблицы:
Имя Возраст Город
Анна 15 Москва
Иван 14 Санкт-Петербург
Мария 15 Казань 

<table>

    <tr>

        <th>Имя</th>

        <th>Возраст</th>

        <th>Город</th>

    </tr>

    <tr>

        <td>Анна</td>

        <td>15</td>

        <td>Москва</td>

    </tr>

    <tr>

        <td>Иван</td>

        <td>14</td>

        <td>Санкт-Петербург</td>

    </tr>

    <tr>
        <td>Мария</td>

        <td>15</td>

        <td>Казань</td>

    </tr>

</table>

Атрибуты ячеек для объединения:

1. Объединение столбцов (colspan)

Атрибут colspan позволяет ячейке занять несколько столбцов:

Пример colspan:
Общий заголовок
Ячейка 1 Ячейка 2 

<table>

    <tr>

        <th colspan="2">Общий заголовок</th>

    </tr>

    <tr>

        <td>Ячейка 1</td>

        <td>Ячейка 2</td>

    </tr>

</table>
2. Объединение строк (rowspan)

Атрибут rowspan позволяет ячейке занять несколько строк:

Пример rowspan:
Объединено Ячейка A
Ячейка B 

<table>

    <tr>

        <td rowspan="2">Объединено</td>

        <td>Ячейка A</td>

    </tr>

    <tr>

        <td>Ячейка B</td>

    </tr>

</table>

💡 Когда использовать таблицы?

Используйте для: расписаний, прайс-листов, статистики, сравнения характеристик.

НЕ используйте для: разметки всей страницы или простого расположения элементов (для этого есть CSS).
