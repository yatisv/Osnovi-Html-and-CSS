📚 1. Теоретический материал

1. Стилизация ссылок (<a>)

Ссылки имеют несколько состояний, которые можно стилизовать с помощью псевдоклассов. Псевдоклассы добавляются к селектору через двоеточие.

  • :link — непосещенная ссылка (по умолчанию).
  • :visited — посещенная ссылка.
  • :hover — при наведении курсора мыши.
  • :active — в момент нажатия кнопки мыши.
Пример стилизации ссылки:
Наведи на меня 
.my-link {
    color: #4361ee;
    text-decoration: none; /* Убираем подчеркивание */
    border-bottom: 2px solid transparent; 
    transition: 0.3s; /* Плавность */
}
.my-link:hover {   /* изменения цвета при наведении */
    color: #e63946;
    border-bottom-color: #e63946;
}

2. Стилизация изображений (<img>)

Изображения в CSS ведут себя как строчно-блочные элементы. Мы можем управлять их размером, формой и внешним видом.

Размеры и скругление

Свойства width и height задают размеры. Свойство border-radius позволяет скруглять углы. Значение 50% делает изображение идеально круглым (при равных ширине и высоте).

Пример круглого изображения:
 .avatar {
    width: 100px;
    height: 100px;
    border-radius: 50%;
    object-fit: cover; /* Чтобы картинка не сплющивалась */
	border: 5px solid #2ec4b6; /* цвет  и толщина рамки  */
}

Свойство object-fit

Когда мы задаем изображению жесткие width и height, оно может исказиться. Свойство object-fit решает эту проблему:

  • cover — масштабирует изображение, заполняя весь контейнер, лишнее обрезается (пропорции сохраняются).
  • contain — масштабирует изображение, чтобы оно целиком поместилось в контейнер.

3. Стилизация кнопок (<button>)

Кнопки по умолчанию выглядят скучно, но с помощью CSS их можно превратить в красивые интерактивные элементы. Основные свойства для стилизации кнопок:

  • background-color — цвет фона кнопки.
  • border — граница (часто используют border: none; для удаления стандартной серой рамки).
  • padding — внутренние отступы, делающие кнопку крупнее и удобнее для нажатия.
  • border-radius — скругление углов.
  • cursor: pointer — меняет курсор на "руку" при наведении, показывая, что элемент кликабельный.
  • :hover — псевдокласс для изменения стиля при наведении (например, затемнение фона).
Пример стильной кнопки:
.my-button {
    background-color: #00BFFF;
    color: white;
    border: none;
    padding: 12px 24px;
    border-radius: 8px;
    font-size: 16px;
    cursor: pointer;
    transition: 0.3s;
}
.my-button:active { /* изменения цвета в момент нажатия кнопки*/
    background-color: #3a56d4;
}

💡 Профессиональный совет:

Чтобы задать ссылке отступы (padding) и сделать из нее кнопку, обязательно добавьте ей свойство display: inline-block; или display: block;. По умолчанию ссылка является строчным элементом, и вертикальные отступы к ней не применяются.
