Тема 8: Семантическая разметка веб-страницы

🏠 Главная / Урок 8: Семантическая разметка

📚 1. Теоретический материал

1. Что такое семантическая разметка?

Раньше веб-страницы собирали из универсальных блоков <div>, которые не несут никакого смысла. Семантическая разметка использует специальные теги, которые говорят браузеру и поисковым системам (Яндекс, Google), какую роль играет содержимое.

💡 Аналогия: Планировка дома

Вместо того чтобы называть все комнаты просто "Комната 1", "Комната 2" (как <div>), мы даем им понятные имена: "Кухня" (<header>), "Гостиная" (<main>), "Кладовка" (<aside>). Это помогает гостям (и поисковикам) сразу понять, где что находится.

2. Основные семантические теги HTML5

  • <header> — "шапка" сайта или раздела (логотип, главный заголовок).
  • <nav> — блок с основными навигационными ссылками (меню).
  • <main> — основное, уникальное содержимое страницы (должен быть только один на странице).
  • <section> — смысловой раздел документа (например, "О нас", "Контакты").
  • <article> — независимый, самодостаточный контент (статья в блоге, новость, комментарий).
  • <aside> — боковая панель или дополнительная информация, косвенно связанная с основным контентом.
  • <footer> — "подвал" сайта (копирайт, контакты, ссылки на соцсети).

3. Введение в Flexbox для разметки

Чтобы расположить блоки (например, основной контент и боковую панель) рядом друг с другом, а не друг под другом, используется CSS-свойство display: flex.

Пример расположения main и aside в ряд:
<main>
Основной контент занимает больше места.
<aside>
Боковая панель. 

.container {
    display: flex; /* Включает гибкое расположение в ряд */
    gap: 10px;     /* Расстояние между блоками */
}
main { flex: 3; }  /* Занимает 3 части пространства */
aside { flex: 1; } /* Занимает 1 часть пространства */

💡 Почему это важно? (ГЛАВНОЕ)

  • 1. SEO (Поисковая оптимизация): Поисковики (Яндекс, Google) лучше понимают структуру вашего сайта и выше его ранжируют.
  • 2. Доступность (Accessibility): Программы чтения с экрана для незрячих людей могут быстро переходить к <main> или <nav>, игнорируя шапку и подвал.
  • 3. Читаемость кода: Вам и другим разработчикам будет гораздо проще ориентироваться в коде, чем в бесконечных контейнерах <div>.
  • 4. Лёгкость поддержки и масштабирования. Код становится более читаемым и удобным для разработки.
  • 5. Соответствие стандартам. Семантическая разметка отвечает рекомендациям W3C (World Wide Web Consortium), что повышает совместимость сайта с различными устройствами и браузерами.

🚀 ГЛАВНОЕ: Сами по себе семантические теги не меняют внешний вид страницы (она выглядит так же, как и с обычными <div>). Они добавляют смысл для браузеров и поисковиков. А красивый внешний вид мы всегда задаем отдельно с помощью CSS!

⛔ Типичные ошибки и как их исправить

  1. Несколько <main> на странице. Должен быть один. Остальные блоки — <section> или <div>>.
  2. <nav> без списка. Внутри меню используйте <ul>/<ol> для логичной структуры ссылок.
  3. <section> без заголовка. У раздела должен быть явный заголовок (<h2>/<h3>). Если заголовок не нужен — возможно, достаточно<div>.
  4. Путаница article/section. Самодостаточный контент — <article>, тематическая группа — <section>.
