📚 1. Теоретический материал

Что такое атрибуты тегов?

В HTML у большинства тегов есть настройки, которые называются атрибутами. Атрибуты указываются внутри открывающего тега и имеют вид имя="значение". Они позволяют уточнить, как именно должен вести себя элемент.


<тег атрибут1="значение1" атрибут2="значение2">Содержимое</тег>

💡 Аналогия: Пульт от телевизора

Тег <img> — это сам телевизор (он показывает картинку). А атрибуты — это кнопки пульта: громкость="50", канал="1", яркость="max". Телевизор один, но настройки у него могут быть разные.

1. Изображения: тег <img>

Для вставки картинок используется тег <img>. Это одиночный тег — у него нет закрывающей части.
У этого тега есть обязательный атрибут src (от source, «источник») говорит браузеру, где искать картинку. Без него тег просто не сработает — на странице ничего не появится.

 <img src="logoSkillbox.png">

Это относительная ссылка. Такой путь указывает на файл, который лежит рядом с HTML-документом — в той же папке.
Если картинка лежит во вложенной папке, путь будет чуть длиннее:

 <img src="images/logoSkillbox.png">

Абсолютная ссылка. Это полный интернет-адрес до изображения, размещённого на внешнем ресурсе. Это может быть URL-адрес, включающий домен и протокол:

 <img src="https://cdn.skillbox.pro/wbd-front/skillbox-static/skillbox.svg">

Главные атрибуты картинки:

  • src (source) — источник. Здесь пишется путь к файлу картинки (например, "photo.jpg") или ссылка из интернета.
  • alt (alternative text) — альтернативный текст. Если картинка не загрузится (или её читает незрячий человек), будет показан этот текст.
  • width и height — ширина и высота картинки в пикселях.
  • title- добавляет всплывающую подсказку — её видно, когда пользователь наводит курсор на изображение.

Пример:

<img src="logoSkillbox.png" 
     alt="Логотип Skillbox" 
     width="300" 
     height="500"
	 title="Эта надпись появится при наведении курсора на логотип">

⛔ Ошибка новичка:

Никогда не забывайте атрибут alt. Поисковики (Google, Яндекс) не "видят" картинки, они читают именно этот текст, чтобы понять, что изображено.

2. Гиперссылки: тег <a>

Ссылки позволяют переходить с одной страницы на другую. Для этого используется парный тег <a> (от англ. anchor — якорь).
Типы ссылок
Атрибут href может содержать разные типы адресов:
Абсолютный URL — полный веб-адрес внешнего ресурса (например, https://example.com).

 <a href="https://skillbox.ru/">Официальный сайт Skillbox</a>
Официальный сайт Skillbox
Относительный URL — указывает путь относительно текущей страницы (например, about.html для ссылки на страницу в текущем каталоге). 
 <a href="about.html">О нас.</a>

URL с фрагментом — например, #section1 для перехода к элементу с id="section1" на той же странице (якорные ссылки).
Особенности
Якорные ссылки позволяют перемещаться между разделами одной страницы. Для этого в нужном месте создаётся элемент с уникальным id, а ссылка формируется с использованием символа # в атрибуте href.

 <section id="about">
    <h2>О нас</h2>
    <p>Этот раздел рассказывает о нашей команде.</p>
 </section>

Создаём ссылку на этот id, добавляя href="#имя":

  <a href="#about">Перейти к разделу «О нас»</a>

Теперь, когда пользователь нажмёт на ссылку, страница прокрутится к нужному блоку.

Важные атрибуты ссылки:

  • href (hypertext reference) — адрес, куда ведет ссылка. Это может быть сайт (https://google.com), файл (file.pdf) или почта (mailto:email@site.com).
  • target — где открыть ссылку. Значение _blank открывает её в новой вкладке.
  • title — добавляет всплывающую подсказку при наведении курсора.
  • download — указывает, что ресурс должен быть загружен при клике.

Пример ссылки:

<a href="https://yandex.ru" target="_blank">Открыть Яндекс</a>

3. Картинка-ссылка

Можно сделать так, чтобы при клике на картинку открывался сайт. Для этого нужно вложить тег <img> внутрь тега <a>.


<a href="https://google.com">
    <img src="google_logo.png" alt="Логотип Google">
</a>

📝 Запомни разницу:

Для картинок мы пишем src (потому что мы "загружаем" файл).
Для ссылок мы пишем href (потому что мы "ссылаемся" на адрес).
Не путай их!
