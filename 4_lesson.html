1. Что такое формы в HTML?

Формы используются для сбора данных от пользователя. Основная информация отправляется на сервер для обработки.

Главный тег формы: <form>

Все элементы формы должны находиться внутри тега <form>. У него есть два важных атрибута:

  • action — адрес (URL), куда будут отправлены данные.
  • method — метод отправки: GET (данные видны в адресной строке) или POST (данные скрыты).
Пример базовой формы:
<form action="/submit" method="POST">
    <label for="username">Имя:</label>
    <input type="text" id="username" name="user_name" placeholder="Введите ваше имя">
    <button type="submit">Отправить</button>
</form>

💡 Зачем нужен тег <label>?

Тег <label> связывает текст с полем ввода. Если атрибут for у label совпадает с id у input, то при клике на текст курсор автоматически перейдет в поле ввода.

Пример textarea и select:
<label for="city">Город:</label>
<select id="city" name="user_city">
    <option value="moscow">Москва</option>
    <option value="spb">Санкт-Петербург</option>
    <option value="kazan">Казань</option>
</select>

<label for="message">Сообщение:</label>
<textarea id="message" name="user_message" rows="3" placeholder="Напишите что-нибудь..."></textarea>

2. Фреймы в HTML

Фреймы позволяют встроить одну веб-страницу внутрь другой. В современном HTML5 используется универсальный тег <iframe> (inline frame).

Основные атрибуты: src (адрес), width и height (размеры), title (описание).

Пример встраивания видео:
<iframe 
    src="вставить ссылку на видео с Rutube" 
    width="560" 
    height="315" 
    title="Rutube video player" 
    allowfullscreen>
</iframe>
