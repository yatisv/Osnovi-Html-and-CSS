🏠 Главная / Урок 6: Блочная модель

📚 1. Теоретический материал

1. Что такое блочная модель?

В CSS каждый элемент на странице представляет собой прямоугольный блок. Блочная модель (Box Model) описывает, из чего складываются размеры этого блока и как он взаимодействует с соседними элементами.

💡 Аналогия: Картина в рамке на стене

  • Content (Содержимое) — сама картина (текст или изображение).
  • Padding (Внутренний отступ) — паспарту (пространство между картиной и рамой).
  • Border (Граница) — сама рама картины.
  • Margin (Внешний отступ) — расстояние от рамы до соседних картин на стене.

2. Основные свойства блочной модели

Внутренний отступ (Padding)

Свойство padding создает пространство внутри элемента, между его содержимым и границей.

Пример:
Текст с отступом 20px
  .box {
    padding: 20px;
}

Граница (Border)

Свойство border рисует линию вокруг элемента. Оно состоит из трех частей: толщина, стиль и цвет.

  • Стили: solid (сплошная), dashed (пунктирная), dotted (точечная), none (без границы).
Пример:
Пунктирная рамка
  .box {
    border: 3px dashed #e63946;
    border-radius: 8px; /* Скругление углов */
}

Внешний отступ (Margin)

Свойство margin создает пространство снаружи элемента, отделяя его от других блоков. Отличный способ центрировать блок — использовать margin: 0 auto; (при условии, что у блока задана ширина).

Пример центрирования:
Я по центру!
  .box {
    width: 200px;
    margin: 0 auto; /* 0 сверху/снизу, auto слева/справа */
}

💡 Профессиональный совет: box-sizing

По умолчанию width задает размер только содержимого, а padding и border добавляются сверху, увеличивая общий размер. Чтобы width включал в себя padding и border, используйте:

 * {
    box-sizing: border-box;
}
