📚 1. Теоретический материал

1. Что такое CSS?

CSS (Cascading Style Sheets) — это язык таблиц стилей. Если HTML — это скелет страницы, то CSS — это её "одежда". С помощью CSS мы задаем цвета, шрифты, отступы и расположение элементов.

💡 Синтаксис CSS:

Правило CSS состоит из селектора (кого стилизуем) и блока объявлений (что меняем)
1. CSS-код размещается непосредственно в HTML-документе внутри тега <style> в секции <head>. 

 <head>
    <style>
	селектор {
    свойство: значение;
    свойство: значение;
}
    </style>
</head>

2. Встроенные стили (inline-стили) — стили прописываются прямо в атрибуте style конкретного HTML-элемента.

 <h1 style="font-size: 32px; color: #333333;">Заголовок</h1>

Селектор по тегу (элементу)
Этот селектор CSS применяет стили ко всем элементам с одинаковым тегом. Например, для всех <div>, <h2>, <p> и так далее.

 h1 {
    color: #e63946;
    font-size: 32px;	
}
<h1> Привет</h2>

Селектор по идентификатору (id)
Селектор по идентификатору обозначается символом # (решётка) и применяет стили к элементу, для которого задан атрибут id с соответствующим значением.

 #intro{
		color: red;
		font-weight: bold;
	}
 <p id="intro">Сегодня мы расскажем вам об селекторах.</p>

Селектор по классу (class)
CSS-селектор по классу обозначается символом . (точка) выбирает элементы, для которых назначен атрибут class с соответствующим значением. 

 .intro{
		color: red;
		font-weight: bold;
	}
 <p class="intro">Сегодня мы расскажем вам об селекторах.</p>

Группа селекторов
CSS-селекторы можно сгруппировать, чтобы применить стили к нескольким группам и/или классам элементов. Для этого достаточно перечислить их через запятую:

 .intro, h1, #in{
		color: red;
		font-weight: bold;
	}

2. Основные свойства для работы с текстом

Цвет и размер текста

  • color — задает цвет текста (по имени, HEX-коду или RGB).
  • font-size — задает размер шрифта (в пикселях px).
Пример:

Привет, мир!

 h1 {
    color: #e63946;
    font-size: 32px;
}

Шрифт и начертание

  • font-family — задает семейство шрифтов (например, Arial).
  • font-weight — задает жирность текста (например, bold).
Пример:

Это жирный моноширинный текст.

 p {
    font-family: 'Courier New', monospace;
    font-weight: bold;
}

Выравнивание и декорирование

  • text-align — выравнивает текст (left, center, right).
  • text-decoration — добавляет украшения (underline для подчеркивания).
Пример:

Текст по центру и подчеркнут

  p {
    text-align: center;
    text-decoration: underline;
}

Межстрочный интервал и регистр

  • line-height — задает высоту строки (например, 1.5).
  • text-transform — управляет регистром (uppercase для ВСЕХ ЗАГЛАВНЫХ).
Пример:

Этот текст написан заглавными буквами и имеет большие отступы между строками.

 p {
    line-height: 2;
    text-transform: uppercase;
}
